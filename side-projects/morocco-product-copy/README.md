# Product Copy Morocco

Micro-tool for Moroccan small merchants.

## V1
- Product name, price, category, audience and product details
- Arabic product description
- French version
- WhatsApp short copy
- Facebook post
- One-click copy
- Mobile-first responsive UI

## Next
- Supabase saved drafts
- AI generation through a secure server endpoint
- Image upload and product-image analysis
- Merchant accounts
- Usage limits and paid credits

The current V1 uses local browser generation only and does not expose any secret API key.
